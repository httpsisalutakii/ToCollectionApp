## To Collection App

Integrantes da equipe: isabelli Luiza

O aplicativo é basicamente focada no nicho do colecionismo, com várias comunidades que você pode fazer parte com os próprios chats de conversa, vendas e etc.

2. Caso voce não tenha instalado em sua máquina, as dependências do expo para rodar esta aplicação são:

  @react-native-async-storage/async-storage<br>@react-navigation/native<br>@react-navigation/native-stack<br>expo<br>expo-camera<br>expo-notifications<br>expo-sqlite<br>expo-status-bar<br>react<br>react-dom<br>react-native<br>react-native-safe-area-context<br>react-native-screens<br>react-native-web

3. Para rodar o seu projeto voce precisa dar o seguinte comando:

npx expo start --tunnel ou somente npx expo start
